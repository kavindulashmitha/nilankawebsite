# nilankawebsite

React and Vite website for Nilanka Ramayake — Beyond Tradition.

## Getting started

Install the dependencies:

```sh
npm install
```

Start the local development server:

```sh
npm run dev
```

Create a production build:

```sh
npm run build
```
